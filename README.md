# 🎧 Dreinnify

Минималистичная платформа рецензий и оценок русскоязычной музыки. Вдохновлено «Рисой за творчество». Полный набор:

- 90-балльная система оценок (5 критериев × 10 баллов × 1.8)
- Telegram-авторизация через собственный бот
- Поиск через **Deezer API** (треки/альбомы/артисты)
- Полное прослушивание через **YouTube Music** + fallback на 30-секундные превью Deezer
- Синхронизированный текст (караоке) в стиле Spotify
- Избранное, профили, топы (день/неделя/месяц)
- Верификация артистов с красивой SVG-галочкой
- Админ-панель со статистикой, модерацией и генератором картинок для номинаций
- Фоновое воспроизведение (MediaSession API)
- Тёмный минималистичный дизайн с эффектом **Liquid Glass**, шрифты Manrope + Unbounded

## Структура

```
dreinnify/
├── server.js              # весь бэкенд (Express + SQLite + Telegram bot + Deezer + YouTube)
├── views/index.html       # единая SPA-страница
├── public/
│   ├── css/app.css        # стили
│   ├── js/app.js          # клиентское SPA (роутинг, плеер, оценки, админка)
│   └── uploads/           # аватары, картинки номинаций
├── data/                  # SQLite база
├── package.json
├── Dockerfile
└── .env.example
```

## Быстрый запуск через Docker

```bash
# 1. Скопируйте .env.example → .env и заполните значения
cp .env.example .env
nano .env

# 2. Сборка образа (устанавливает ffmpeg + все зависимости)
docker build -t dreinnify .

# 3. Запуск (монтируем .env, data/, uploads/)
docker run -d \
  --name dreinnify \
  -p 3000:3000 \
  --env-file .env \
  -v $(pwd)/data:/app/data \
  -v $(pwd)/public/uploads:/app/public/uploads \
  dreinnify
```

## Локальный запуск (без Docker)

```bash
# Нужен Node.js 20+, ffmpeg, зависимости canvas (см. Dockerfile)
npm install
cp .env.example .env
# заполните .env
npm start
```

## Настройка Telegram-бота

1. Откройте [@BotFather](https://t.me/BotFather), создайте бота командой `/newbot`.
2. Полученный токен → в `.env` как `BOT_TOKEN`.
3. Username бота (без `@`) → в `BOT_USERNAME`.
4. Ваш Telegram ID (узнать у [@userinfobot](https://t.me/userinfobot)) → в `ADMIN_ID`.

Готово. При открытии сайта нажмите «Войти» → откроется бот → жмёте `/start` → возвращаетесь на сайт, авторизация произойдёт автоматически.

## API endpoints

| Метод | Путь | Описание |
|-------|------|----------|
| GET   | `/api/search?q=` | Поиск треков/альбомов/артистов (русские вперёд) |
| GET   | `/api/track/:id`, `/api/album/:id`, `/api/artist/:id` | Данные из Deezer |
| GET   | `/api/stream?q=` | Аудио-стрим (YouTube Music) |
| GET   | `/api/lyrics?q=` | Текст трека для караоке |
| POST  | `/api/review` | Опубликовать оценку/рецензию |
| GET   | `/api/reviews?item_type=&item_id=` | Все оценки объекта |
| POST  | `/api/favorite` | Toggle избранного |
| GET   | `/api/top?type=&period=` | Рейтинги |
| POST  | `/api/verify/request` | Отправить заявку на верификацию |
| GET   | `/api/admin/*` | Админ-эндпоинты (только для ADMIN_ID) |

## Критерии 90-балльной системы

| Критерий | 0–10 |
|----------|------|
| Рифмы / Образы | сложность рифм, метафоры, панчи |
| Структура / Ритмика | флоу, попадание в бит, схема |
| Реализация стиля | атмосфера, звук, подача |
| Индивидуальность / Харизма | уникальность, эмоция |
| Атмосфера / Вайб | послевкусие, целостность |

**Итог:** сумма × 1.8 = /90

## Требования верификации

- > 5 000 подписчиков в одной соц. сети (IG/YT/TikTok/VK/TG), **или**
- > 50 000 суммарных прослушиваний артиста на стримингах, **или**
- регулярные упоминания в СМИ / профильных медиа
- Видео-подтверждение: запись, где вы вслух говорите «Я — <ник>, подтверждаю Dreinnify» и показываете свои соц. страницы
